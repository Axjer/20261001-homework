# 幸運物動態互動網頁 - Casio F91W

## 學生資訊
* **學號_名字**：514170014_邱冠傑

## 專案介紹
這是一個基於 HTML、CSS 與 JavaScript 製作的動態互動網頁，主題是我的考試幸運物 —— 經典電子錶 **Casio F91W**。因為每當考試時戴著這隻錶，總能讓我考得比較好，所以特別選擇它作為主題。

本專案實作了手錶的經典 LCD 螢幕顯示，包含時間、星期與日期，並加入了滑鼠懸停 (Hover) 的「幸運金光」浮動特效與按鍵點擊 (Click) 的下壓動畫，既還原了真實手錶的操作體驗，又增添了幸運物的趣味性。

## 檔案儲存結構與說明
本專案的所有檔案儲存於本機的 `Course/casio-f91w` 目錄下：

- `index.html`：網頁的主結構與內容，包含手錶的外觀框架與互動說明，並特別註記了考試幸運物的故事。
- `style.css`：負責視覺設計與動態互動效果（包含手錶懸浮動畫、滑鼠懸停放大與發光、以及按鈕 click 時的下壓及顏色反饋）。
- `script.js`：處理手錶的邏輯功能，包含時間的即時更新、背光點亮、12/24小時制切換以及計時碼表功能。
- `README.md`：本說明文件，記錄專案結構與學生資訊。

## 如何執行
1. 打開資料夾找到 `index.html`。
2. 對檔案點擊兩下，或點擊右鍵選擇「在瀏覽器中開啟」（例如 Chrome、Edge、Safari）。
3. 即可開始與你的專屬幸運物進行互動！
